
# StyleStudio

A responsive fashion boutique website built with HTML and CSS.

## Features
- Blush-pink design
- Fashion collections and product cards
- About and contact sections
- Responsive layout
- Apache deployment with Docker

## Docker
Build the image with `docker build -t stylestudio .`.

Run it with `docker run -d --name stylestudio-container -p 8081:80 stylestudio`.
